# PLA-000 PRD — plasticity 助手 v1

## 背景与目标
Plasticity 3D（Studio 26.1.3，Electron）无历史树，操作仅 Ctrl+Z。PLA 助手=外挂程序，提升建模效率。
原型结论（2026-10-15 实测）：
- CDP 注入不可行（商业版加固剥离 remote-debugging switch，端口 0 监听）
- bridge WebSocket 官方协议全通：握手/枚举/解码 367KB 实测干净
- 用户环境：bridge server 已开（0.0.0.0:8980），机器 LAN IP 192.168.123.208

## 用户四项硬要求
1. 快照瞬时切换（兜底=文件级已证为唯一可行，接受秒级切换、新窗口打开不关当前窗）
2. Studio 版
3. Tauri 单 exe 绿色免安装（无注册表/UAC/管理员权限）
4. 支持 Plasticity 多窗口/多文档

## 功能范围 v1
### P0-1 快照管理器（核心）
- 手动快照：热键/按钮触发，保存 .plasticity 副本 + bridge 拉实体清单做缩略图元数据
- 自动快照：定时（N 分钟）+ 定步数（NEW_VERSION 事件计数）
- 快照墙 UI：缩略图网格（v1 用视口外截图替代方案——bridge 无相机通道，v1 缩略图用实体清单+时间戳卡片，P1 再议截屏）
- 切换：调用系统打开副本文件 → 新窗口；管理器记录每个快照所属主文档
- 清理策略：按数量上限（默认 50）/按时间（默认 7 天）/手动；快照另存为独立文件
### P0-2 选择集
- 从 bridge LIST_ALL 拉实体树（含 name/id/groups/face_ids）
- UI 勾选实体/组 → 保存为命名选择集（本地 JSON 库，按文档名归档）
- 一键应用：PUT_SOME 建同名组推回 Plasticity → 用户在 Plasticity 内点组即选中
### P1-1 尺寸驱动（平移类）
- 定义「尺寸关联」：选择集 + 方向向量 + 数值
- 改数值 → 读实体 facet → 顶点平移 → PUT_SOME 写回替换
- 限制如实声明：拓扑类（倒角/圆角半径）不支持；实体替换后 Plasticity 侧原对象删除重建（undo 语义与原生不同）
### P2（v1 不做，登记）
- 视角保存恢复（无通道，待官方 scripting API）
- 拓扑类尺寸驱动
- SolidWorks 式配置（= 快照+选择集+尺寸关联 组合包，P0/P1 交付后自然衍生）

## 非功能约束
- Tauri(Rust)+WebView 前端，产物单 exe；配置/快照库存 exe 同级目录（绿色）
- 多窗口：按 bridge 报告的 filename 区分文档，快照库按文档分目录
- 断线重连：bridge server 心跳（SUBSCRIBE_ALL 保活）
- Windows 10+；不触发 SmartScreen 的措施：不签名但提供使用说明（首次运行"更多信息→仍要运行"）

## 验收标准（v1）
